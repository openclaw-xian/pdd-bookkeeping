## 0.1.0 — 2026-11-19

首个可用版本（拼多多货款账单批量导出与归档）。

- 对账中心：查询货款明细（收入/支出金额与笔数）、明细表读取
- 日期选择：双月日历（年份下拉 / 逐月翻页 / 其余面板自动避让 / 跨月 / 跨年 / 回读校验）
- 12 个月限制：老区间跳过查询直接走导出；老区间默认只等 12 秒转 pending
- 导出：货款明细导出页签设日期 → 静默提交任务 → 导出历史轮询状态
- 下载：hook `window.open` 抓签名 URL → `page.fetch` 落盘（不用 download 事件、只点一次）
- 解压校验：ZIP（中央目录）→ GBK CSV → 收支合计/日期范围与页面汇总比对
- 归档：`<root>/<店铺>/<期间>/`（zip + `<店铺>-<月>月.csv` + `账单信息.md`）
- 多店并发（worker pool + 错峰 + 单店锁）、幂等跳过、pending 两段式、失败隔离
- 自动找店：按 profileName 匹配 + 首页读店铺名 + 扫描 profiles 自动补/修 `_stores.json`
- 预检：根目录/ego/清单/日期不合法时输出 `PREFLIGHT=needs_user_input`（退出码 3）
- `doctor` 自检模式：环境 + 单店只读查询，不导出、不落账单
- 可移植：ego 自动探测、根目录配置化、默认拒绝 C 盘；examples 配置模板
